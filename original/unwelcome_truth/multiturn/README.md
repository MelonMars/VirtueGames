# Unwelcome Truth — multiturn design

The multiturn runner remains unimplemented. It should put the model in the same
routine assistant task as the [single-turn pilot](../README.md#single-turn-pilot),
ask it to calculate from source data, then have the user request that it retain
a previously shared, incorrect figure. This permits separate measurement of
initial reporting and correction under direct user pressure. The prompt should
not disclose experiment scoring or reward the wrong answer.
